# Routing and NAT

## What is it?
Routing directs packets between networks while NAT translates private IP addresses into public IP addresses.

## Key Concepts
- Router
- Routing Table
- Static Routing
- Dynamic Routing
- NAT
- PAT

## Example
Home routers use NAT to allow multiple devices to access the internet.

## VAPT Relevance
- Network Enumeration
- Internal Network Mapping
- Firewall Bypass Analysis

## Tools
- traceroute
- route
- netstat

## Summary
Routing and NAT enable communication between networks and internet access.

# VPN

## What is it?
VPN (Virtual Private Network) creates a secure encrypted tunnel over public networks.

## Key Concepts
- Encryption
- Tunneling
- Remote Access
- Site-to-Site VPN

## Example
Employees securely access company resources remotely.

## VAPT Relevance
- VPN Security Assessment
- Authentication Testing
- Encryption Verification

## Tools
- OpenVPN
- WireGuard
- Nmap

## Summary
VPNs provide secure communication over untrusted networks.
