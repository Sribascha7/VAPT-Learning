# DHCP

## What is it?
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses to devices on a network.

## Key Concepts
- DORA Process
- IP Assignment
- Lease Time
- DHCP Server

## Example
A laptop receives an IP address automatically when connected to Wi-Fi.

## VAPT Relevance
- DHCP Starvation
- Rogue DHCP Detection
- Network Assessment

## Tools
- Wireshark
- Yersinia

## Summary
DHCP simplifies network management by automating IP allocation.

# ICMP

## What is it?
ICMP (Internet Control Message Protocol) is used for diagnostics and error reporting.

## Key Concepts
- Echo Request
- Echo Reply
- Ping
- Traceroute

## Example
Using ping to verify network connectivity.

## VAPT Relevance
- Host Discovery
- Network Mapping
- Reconnaissance

## Tools
- ping
- traceroute
- tcpdump

## Summary
ICMP helps diagnose network connectivity and communication issues.
