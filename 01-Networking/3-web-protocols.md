# DNS

## What is it?
DNS (Domain Name System) translates domain names into IP addresses.

## Key Concepts
- DNS Records
- A Record
- MX Record
- CNAME Record
- DNS Resolution

## Example
google.com → 142.250.x.x

## VAPT Relevance
- Subdomain enumeration
- DNS misconfiguration detection
- Information gathering

## Tools
- nslookup
- dig
- dnsenum

## Summary
DNS enables users to access websites using names instead of IP addresses.

# HTTP and HTTPS

## What is it?
HTTP and HTTPS are protocols used for web communication.

## Key Concepts
- GET
- POST
- PUT
- DELETE
- Headers
- Cookies
- Sessions

## Example
Accessing a website using a browser.

## VAPT Relevance
- Web application testing
- Session management analysis
- Authentication testing

## Tools
- Burp Suite
- OWASP ZAP
- Postman

## Summary
HTTP transfers web data while HTTPS encrypts communication.

# SSL/TLS

## What is it?
SSL/TLS secures data transmitted over networks through encryption.

## Key Concepts
- Certificates
- Public Key Encryption
- Private Key Encryption
- TLS Handshake

## Example
HTTPS websites use TLS to secure communication.

## VAPT Relevance
- Certificate validation
- Weak cipher identification
- SSL/TLS misconfiguration testing

## Tools
- OpenSSL
- SSLScan
- testssl.sh

## Summary
TLS protects sensitive information from interception during transmission.
