# TCP/IP Model

## Overview

The TCP/IP Model is the practical networking model used on the Internet. It consists of four layers that enable communication between devices.

## Core Concepts

- Application Layer
- Transport Layer
- Internet Layer
- Network Access Layer

## How It Works

Each layer performs a specific function and passes data to the next layer for transmission.

## Practical Example

When visiting a website:
- HTTP works at the Application Layer.
- TCP works at the Transport Layer.
- IP works at the Internet Layer.

## Common Commands

```bash
netstat -tulnp
ss -tulnp
tcpdump
```
