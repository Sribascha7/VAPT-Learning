# Subnetting

## Overview

Subnetting divides a large network into smaller logical networks called subnets. It improves efficiency, security, and management.

## Core Concepts

- Subnet Mask
- CIDR Notation
- Network Address
- Broadcast Address
- Host Range

## How It Works

A subnet mask separates the network portion from the host portion of an IP address.

## Practical Example

```text
IP Address: 192.168.1.10/24

Network Address: 192.168.1.0
Broadcast Address: 192.168.1.255
```

## Common Commands

```bash
ipcalc 192.168.1.10/24
```

## VAPT Relevance

- Scope Identification
- Network Segmentation Analysis
- Host Enumeration

## Summary

Subnetting helps security professionals understand network boundaries and identify reachable systems.
