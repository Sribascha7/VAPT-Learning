# IP Addressing

## Overview

An IP address uniquely identifies a device on a network. It allows systems to communicate and exchange information.

## Core Concepts

- IPv4
- IPv6
- Public IP Address
- Private IP Address
- Static IP
- Dynamic IP

## How It Works

Each device receives an IP address that enables routing and communication across networks.

## Practical Example

```text
IPv4 Address: 192.168.1.10
Subnet Mask: 255.255.255.0
```

## Common Commands

```bash
ip addr
ifconfig
hostname -I
```

## VAPT Relevance

- Host Discovery
- Target Enumeration
- Network Mapping

## Summary

IP addressing is one of the most important networking concepts for penetration testing and security assessments.
