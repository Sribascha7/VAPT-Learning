# OSI Model

## What is it?

The OSI (Open Systems Interconnection) Model is a conceptual framework that explains how data travels across a network through seven layers.

## Key Concepts

* Physical Layer
* Data Link Layer
* Network Layer
* Transport Layer
* Session Layer
* Presentation Layer
* Application Layer

## Example

When opening a website, data passes through all seven OSI layers before reaching the destination.

## Overview

The OSI (Open Systems Interconnection) Model is a seven-layer framework used to understand network communication.

## Core Concepts

1. Physical Layer
2. Data Link Layer
3. Network Layer
4. Transport Layer
5. Session Layer
6. Presentation Layer
7. Application Layer

## How It Works

Data moves from the Application Layer down to the Physical Layer on the sender's side and travels back up the layers on the receiver's side.

## Practical Example

When browsing a website:
- HTTP → Application Layer
- TCP → Transport Layer
- IP → Network Layer
- Ethernet → Data Link Layer
