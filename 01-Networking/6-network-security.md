# Firewalls

## What is it?
A firewall filters network traffic based on predefined security rules.

## Key Concepts
- Packet Filtering
- Stateful Inspection
- NGFW
- Access Control Rules

## Example
Blocking inbound traffic to sensitive services.

## VAPT Relevance
- Firewall Rule Review
- Network Segmentation Analysis
- Access Control Testing

## Tools
- Nmap
- Wireshark

## Summary
Firewalls protect systems by controlling network traffic.
